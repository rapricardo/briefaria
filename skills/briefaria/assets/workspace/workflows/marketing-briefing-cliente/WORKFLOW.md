# marketing-briefing-cliente

Use quando receber um pedido inicial, áudio, mensagem curta ou tarefa da fila que precisa virar briefing.

## Passos
1. Identifique cliente, objetivo, canal, oferta, público, prazo e restrições.
2. Leia `clientes/{slug}/brand-context.md` e o que o Mapa de leitura dele indicar antes de preencher lacunas.
3. Separe fato fornecido de suposição.
4. Gere um briefing curto com lacunas explícitas.
5. Se faltar informação crítica para executar, marque `PENDENTE`, mas proponha o próximo passo possível.

## Saída
```md
CLIENTE:
OBJETIVO:
PÚBLICO:
CANAL:
OFERTA/CTA:
PRAZO:
RESTRIÇÕES:
INSUMOS DISPONÍVEIS:
LACUNAS:
PRÓXIMO PASSO:
```
