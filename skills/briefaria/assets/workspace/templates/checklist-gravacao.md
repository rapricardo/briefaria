# Checklist de Gravação (OBS)

## Antes

- [ ] Cenário limpo e organizado
- [ ] Iluminação posicionada e testada
- [ ] Câmera enquadrada e foco ajustado
- [ ] Microfone conectado e nível de áudio verificado
- [ ] OBS aberto com cena correta selecionada
- [ ] Resolução e FPS configurados (1080p / 30fps)
- [ ] Pasta de destino definida no OBS
- [ ] Teste de gravação de 10s — revisar áudio e vídeo

## Durante

- [ ] Gravar claquete verbal (nome do projeto, take)
- [ ] Monitorar indicador de gravação ativo no OBS
- [ ] Verificar nível de áudio periodicamente
- [ ] Pausar entre takes para facilitar edição
- [ ] Anotar timecodes de erros ou repetições

## Depois

- [ ] Parar gravação e confirmar arquivo salvo
- [ ] Revisar início e fim do arquivo gravado
- [ ] Renomear arquivo com padrão: `{cliente}_{projeto}_{take}.mkv`
- [ ] Mover para pasta de produção do cliente
- [ ] Backup do arquivo original
- [ ] Anotar observações relevantes para edição
