# Rubrica — Mapa de teses (G2)

Checkpoint obrigatório. O site inteiro é avaliado **só** por mapa + função + tese de
cada página, antes de qualquer página completa ser escrita.

Formato do mapa: uma linha por página.

```
{página} · {função local} · {entrada típica} · {próximo passo} · {tese}
```

## Critérios

**1. Cobertura de jornada** — Toda jornada declarada em `02-decisoes/jornadas.md` tem
caminho completo, da entrada ao próximo passo? Jornada sem página de entrada é buraco.

**2. Página sem missão** — Existe página cuja função local não se distingue da de
outra? Duas páginas com a mesma função e o mesmo público são uma página. Página que
existe porque "sites costumam ter" sai.

**3. Colisão de teses** — Duas teses disputam o mesmo momento mental do visitante?
Se sim, uma delas está no lugar errado do fluxo.

**4. Conflito com a função dominante** — Alguma página exige do visitante um
comportamento que a função dominante sacrifica?

**5. Teses individualmente aprovadas** — Toda tese do mapa já passou pela rubrica
`tese.md` com veredito aprova. Mapa com tese não avaliada não vai a gate.

**6. Órfãs** — Toda página tem pelo menos uma entrada declarada de outra página ou de
canal externo. Página com uma única entrada interna precisa justificar existência.

## Veredito

`aprova` só com os seis limpos. Qualquer pendência vira `revisa` com a lista das
páginas afetadas. O mapa vai para `fila/4-humano/` — aprovação de G2 é humana, sempre.
