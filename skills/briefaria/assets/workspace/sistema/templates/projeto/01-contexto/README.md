# 01 — Contexto

`economia.md` — como o dinheiro entra: quem paga, quanto, quando, quem carrega risco.
Errar isto invalida todo o resto do projeto.
`icp.md` — para quem, com critério observável de qualificação.
`provas.md` — duas listas. **Disponíveis**: número, caso e nome que podem ser usados,
com origem. **Vetadas**: o que existe mas não pode ser publicado, e por quê. O produtor
precisa reconhecer e recusar, então o vetado fica escrito.
`concorrencia.md` — quem mais o visitante está considerando, e o que já dizem.
